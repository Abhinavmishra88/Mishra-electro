# ⚡ Mishra Electro

A full-stack electrical products e-commerce website built with React + Vite and Spring Boot.

## 🚀 Features

- 🛒 Product shopping and cart management
- ❤️ Wishlist functionality
- 🔍 Product search
- 📦 Product categories
- 👤 User registration and login
- 🔐 Authentication and password management
- 👨‍💼 Admin dashboard
- 📋 Product management
- 👥 Customer management
- 🧾 Order management
- 📍 Address management
- 💳 Razorpay payment integration
- 📦 Order tracking
- 📱 Responsive design
- 🎨 Theme support

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- React Router
- Bootstrap
- Bootstrap Icons
- JavaScript
- CSS

### Backend

- Java
- Spring Boot
- Spring Data JPA
- REST APIs
- Maven

### Database

- MySQL

### Payment

- Razorpay
